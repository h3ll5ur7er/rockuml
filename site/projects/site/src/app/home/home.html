PlantUML-compatible · Rust · WebAssembly

Diagrams as code, without the JVM.

rockuml draws PlantUML diagrams with one small binary for Windows, Linux and macOS. No Java, no Graphviz, no server. Its WebAssembly build even runs right here in your browser: edit the diagram below.

Get started Open the playground Download

One binary, zero runtimes

A single executable per platform. The fonts, themes and the PlantUML standard library are built in, so every machine draws the same image.

Speaks PlantUML

Your existing .puml files work as they are. rockuml is tested against PlantUML 1.2026.8 on hundreds of reference diagrams, down to the coordinates of every line.

Runs in the browser

The same engine compiled to WebAssembly renders diagrams client-side. Use it from JavaScript, or drop the Angular components into your app.

Plugs into your editor

Start rockuml --http-server and point the PlantUML plugin of VS Code or JetBrains at it. Live previews, no Java in sight.
